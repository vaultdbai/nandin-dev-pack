# Nandi Dev Pack

Official agents for [Nandi](https://vaultdb.ai). No account and no key beyond your own model key.

| Agent           | What it does                                                                     | Status   |
| --------------- | -------------------------------------------------------------------------------- | -------- |
| PR Reviewer     | Reviews a pull request (private repos too) against your rules and posts the review after approval | Preview  |
| AWS Ops Analyst | Investigates failed AWS Batch jobs and CloudWatch alarms from their logs and proposes fixes you approve | Preview |

Each agent's rules are yours: change them in the agent's **Settings › Your rules**. Nandi keeps them beside the install, so updates to this pack keep them. `skill.md` holds how the agent works.

`examples/my-notes/` is a sample notes folder to try Chief of Staff with. Chief of Staff comes with Nandi itself, so it isn't in this pack.
